Button

<juel-button> is a themed button/submit control. Colour comes from the type attribute, styling from render-style, and it can carry a glyph icon, prepend/append slots, or a dropdown.

Types

The type attribute selects the semantic colour. Values are lower-case and match AlertTypes.

Render style

render-style="outline" swaps the filled background for an outlined variant.

Icons

The glyph attribute renders a built-in icon alongside the label.

Prepend / append

Content placed in the prepend and append slots renders either side of the label.

Left Middle Right

Dropdown

Content in the dropdown slot opens beneath the button.
