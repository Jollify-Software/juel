Icon Button

<juel-icon-button> is a circular, icon-only button. icon accepts a built-in glyph name, an emoji, or a data URL; label is required for accessibility even though it isn't shown.

Glyph icons

A built-in icon name renders via the same icon set as juel-button's glyph.

Types

Like juel-button, the type attribute selects the semantic colour.

Emoji

Any emoji works directly as the icon value, no glyph name needed.
