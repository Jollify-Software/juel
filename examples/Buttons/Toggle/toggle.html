Toggle

<juel-toggle> is a switch-style checkbox. It can show a label, an icon, or cycle through more than two states, and its singular mode makes a group of toggles behave like a radio group.

Basic

With no attributes it's a plain on/off switch. rounded gives it pill-shaped ends.

Icon & label

glyph takes one icon per state, pipe-separated (off|on). Add label the same way to show text instead of the switch track.

More than two states

states takes a pipe-separated list of button type colours to cycle through on each click; pair it with a matching label list.

Singular (exclusive) groups

singular="true" makes clicking one toggle un-check the others in its group — radio-button-like behaviour. Note this is not a robust name-based group: by default the group is whatever <juel-toggle> siblings share the same parent element, so restructuring the surrounding markup can silently split a group apart.

Singular, contained

contained="true" plus a container selector scopes the exclusive group to the nearest ancestor matching that selector, instead of direct siblings — useful when each toggle is wrapped in its own element, like a list item.
