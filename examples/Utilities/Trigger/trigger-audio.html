Trigger — Audio

<juel-trigger selector="..." event="click"> attaches a listener to the element its selector matches. When the event fires it runs each child <juel-trigger-action>: it looks up that action's own selector and calls the method named by action on it. Point the action at a plain <audio> element with action="play" and a click on the shape plays the sound — no script.

Click the star

The <juel-shape> star has id="star". The trigger listens for click on it and calls play() on the <audio id="star-chime"> element.

Different shapes, different sounds

Each shape is an independent <juel-trigger> pointed at its own <audio> element. A native <audio>.play() call is a no-op while that clip is still playing, then rewinds and replays once it has ended.

How it resolves

juel-trigger binds the listener in its ready() hook, so the selector target only has to exist by the time the DOM is ready — order on the page doesn't matter. action is any method name that exists on the resolved element; <audio> gets play, pause and load for free from HTMLMediaElement. There's also a built-in action="addClass" that uses the action's arguments attribute as the class name.
