Countdown

<countdown-timer start="..." end="..." time="..."> ticks numerically from start to end over time milliseconds, firing a tick event on every step. Once the value crosses threshold, it applies an animation CSS class (default pulse) each tick.

Basic

Counts down from 10 to 0 over 5 seconds; pulses once it reaches the threshold of 3.

Counting up

start < end counts upward instead.
