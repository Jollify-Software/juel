Animate — Triggers

<juel-trigger selector="..." event="..."> listens for an event on a matching element and runs the <juel-trigger-action> children's action (a method name) on their own selector target. juel-animate dispatches animation-start, animation-pause, animation-end, and animation-stop — wiring a trigger to animation-end lets one animation kick off the next.

Chained ping-pong

Clicking the button plays the red square's animation; each square's animation-end triggers the other one to play, so they hand off back and forth indefinitely.
