Preload

<juel-preload type="all"> waits for every image on the page to finish loading — both real <img> elements (type="element") and CSS background-image: url(...) references found in any <style> block (type="css"). It exposes the result as window.assetsReady, a promise consumers can await, plus a window.waitAssetsReady() helper.
