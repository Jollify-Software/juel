Media

<juel-media src="..."> renders an image, video, or audio player, auto-detected from the URL's extension or hostname. background makes it fill its (positioned) container muted/looping/autoplaying; alt sets image alt text; blend composites multiple space-separated image sources with a CSS background-blend-mode.

Image

A plain <img> is rendered when the source isn't a recognised video/audio type.

Video (controls)

A recognised video extension (or platform hostname) renders a <video> with controls.

Background video

background switches to an autoplaying, muted, looping video that fills its container — the host becomes absolutely positioned, so wrap it in a position: relative box.

Blended images

Multiple space-separated image sources with blend composite together via background-blend-mode.
