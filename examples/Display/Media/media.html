Media

<juel-media src="..."> renders an image, video, or audio player, auto-detected from the URL's extension or hostname. background makes it fill its (positioned) container muted/looping/autoplaying; alt sets image alt text; blend composites multiple space-separated image sources with a CSS background-blend-mode.

Three presentation effects can be layered on with boolean attributes: shadow (a drop shadow that follows the media's alpha shape), reflection (a fading mirror image below), and feather (soften all edges, or just feather="top left", with an inset glow). Each is tuned with CSS custom properties.

Image

A plain <img> is rendered when the source isn't a recognised video/audio type.

Video (controls)

A recognised video extension (or platform hostname) renders a <video> with controls.

Background video

background switches to an autoplaying, muted, looping video that fills its container — the host becomes absolutely positioned, so wrap it in a position: relative box.

Blended images

Multiple space-separated image sources with blend composite together via background-blend-mode.

Shadow

shadow drops a shadow beneath the media with drop-shadow() — on a transparent PNG or SVG it follows the actual shape, not the bounding box. Override --media-shadow for a custom offset / blur / colour.

Reflection

reflection adds a fading mirror image below the media (via -webkit-box-reflect, supported in Chromium / WebKit). Tune it with --reflection-gap, --reflection-color and --reflection-length.

Feather

feather softens the edges with an inset glow — box-shadow: 0 0 8px 8px white inset. Set --feather-color to match the page background and --feather-size for the spread.
