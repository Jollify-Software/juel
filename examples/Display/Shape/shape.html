Shape

<juel-shape type="..."> paints a shape layer behind its slotted content. type resolves to a built-in geometric shape (a CSS clip-path, so it scales with no JavaScript), or a matching icon glyph, or — with a slotted <template> — a fully custom SVG. Fill with --fill; rotate the shape layer with direction; reveal it on hover with hover.

Default

With no type, a circle sits behind the slotted content.

Built-in geometric shapes

Each is a percentage-based clip-path on a plain filled box. Add your own at runtime with juel.shape.registerShape(name, points).

Fill

--fill takes any CSS background value — a colour, or a gradient.

Direction

direction rotates the shape layer to a compass point (n, ne, e, …); slotted text stays upright.

N E S W

Icon fallback

A type that isn't a geometric shape falls back to a matching icon glyph.

Custom SVG template

A slotted <template> supplies a fully custom shape — themeable through its own var(--*) hooks. See keep-calm.html for named sub-templates and foreignObject text.

Hover reveal

hover on its own morphs a plain rectangle into type on hover; hover="<shape>" morphs type into that shape. Full demo: hover.html.
