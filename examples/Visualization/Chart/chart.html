Chart

<juel-chart type="..."> renders a chart from one or more <juel-chart-series> children, each supplying a label, color, and data. Values in data are comma-separated ("10, 20, 15"); scatter series use x:y pairs instead ("1:2, 2:4").

Bar

Grouped columns per labels category.

Stacked bar

Series stack on top of each other instead of grouping side by side.

Line

One point per label, connected in order.

Area

Same as line, filled down to the axis.

Pie

Each series contributes a single value (its data's first entry) as one slice.

Doughnut

A pie chart with a hollow center.

Radar

One axis per label, one polygon per series.

Scatter

Series data is a list of x:y pairs instead of plain values.

Gauge

Each series is a needle; min/max set that series' scale.
