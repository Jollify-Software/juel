Scroll Spy

<juel-scrollspy> highlights which <juel-scrollspy-item href="#id"> corresponds to whatever section is scrolled into view. target names the CSS selector of the scrollable container to watch — leave it unset to watch the page itself. Clicking an item smooth-scrolls to its section.

Basic

Scroll the panel on the right, or click a link to jump to a section.

Introduction Installation Usage FAQ

Introduction

Juel is a Lit-based web component library — every element ships as a plain custom element, usable from any framework or none at all.

Installation

Add a single script tag pointing at dist/juel.js. No bundler or build step is required to start using the components.

Usage

Once the script has loaded, every juel-* element is defined and can be used directly in HTML, exactly like a built-in tag.

FAQ

Questions not covered here can be raised against the component library's issue tracker.
