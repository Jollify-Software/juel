Toolbar

<juel-toolbar> lays out arbitrary slotted content — buttons, labels, inputs, anything — in a row. A direct child with class spacer grows to fill remaining space, pushing everything after it to the far end. Use direction="vertical" for a side rail, and theme it via CSS custom properties.

Basic

A spacer child pushes everything after it to the right.

Vertical

direction="vertical" stacks content in a column, for a sidebar-style rail.

Wraps on narrow screens

Content wraps onto a new line instead of overflowing when there isn't room for it all.

Theming

--toolbar-background-color, --toolbar-color, --toolbar-padding, --toolbar-gap and --toolbar-box-shadow style the bar.
