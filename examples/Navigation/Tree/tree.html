Tree

<tree-menu> renders a collapsible tree two ways: declaratively, by nesting <tree-branch>/<tree-leaf> elements in markup, or from data, by setting its data property to an array. Set selectable to let visitors pick a node — true, false, branchesOnly, or leavesOnly — and listen for node-selected.

Declarative

Nest <tree-branch label="…"> and <tree-leaf label="…"> directly in markup. Click a chevron to expand, click a checked row to select it.

Data-driven

Set data to an array of objects — labelField/itemsField name which keys hold the label and children.

Reacting to node-selected

Listen for node-selected to react elsewhere on the page.
