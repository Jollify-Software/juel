Nav

<juel-nav> is a header bar for a title-slotted logo and a row of menu items. It collapses to a hamburger menu at 768px and narrower, can sticky itself to the top of the page on scroll, and themes via CSS custom properties. Nest a <juel-item> with an items slot for a dropdown submenu.

Basic

A title and a row of items, given via the default slot.

Dropdown submenu

A <juel-item> with content in its items slot opens a floating dropdown on hover.

Below 768px viewport width the item row is replaced by a hamburger toggle — resize your browser to see it.
