Field Form

<juel-form> renders a set of editor fields from a plain .fields array ({ name, label, type, value }), each backed by the matching Juel editor (juel-text, juel-number, juel-email) and writing back into the same field object's value as the user types. (For a schema-driven single form with its own submit button, see Editors › Form, registered as <juel-form-layout>.)
