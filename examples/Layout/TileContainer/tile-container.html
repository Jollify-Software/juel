Tile Container

<juel-tile-container> lays out its tiles in a scrollable strip or wrapping grid — either as light-DOM children, or bound to a data array rendered through a .template string (with this bound to the record, same convention as juel-data-grid). Set direction="horizontal" for a single scrolling row instead of the default wrapping grid. Drag with the mouse or a finger to scroll — powered by Hammer.js — or set touch="false" to fall back to plain native scrolling. Listen for tile-click to react to a tile being selected.
