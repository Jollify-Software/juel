Position Editor

<juel-position-editor> visually edits a two-axis CSS <position> value — transform-origin, object-position, background-position, perspective-origin. Point it at an element with for; the picker overlay then tracks that element's box and reports the click as a percent / px / keyword position of it. With css-property set it writes the value live while you drag. Every committed pick is an undo step — the ↶ / ↷ arrows (or undo() / redo()) walk the history. Esc or right-click cancels a pick.
