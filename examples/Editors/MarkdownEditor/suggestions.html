Markdown Editor: suggestions while typing

Give <juel-markdown-editor> a suggestions list of { after, label, detail, insert, info }. Type ::: at the start of a line and a list drops down; Enter or Tab takes one, with the cursor on its first ${…} field (Tab to the next). ![ asks the suggest callback (here, a list of images). The info panel's "More in the guide" fires suggestion-help. suggestions-live="false" (the second editor) opens the list only on Ctrl+Space. Open with ?look&theme=dark for the dark look.
