Markdown Editor

<juel-markdown-editor> is a CodeMirror 6 editor with Markdown syntax highlighting. Set the initial text with the content attribute/property. Every edit by the user fires content-changed with { content }; setting content from outside updates the editor in place and doesn't fire it. Cursor moves fire cursor-changed with { offset, line, column }.

Cursor, insert, warnings and read-only

setCursor(offset) moves the cursor and scrolls to it; revealOffset(offset) only scrolls; insertAtCursor(text) inserts as the user's own (undoable) edit; wrapSelection toggles a wrapper round the selection; toggleLinePrefix toggles a list or quote prefix on the selected lines; insertBlock inserts a block on its own lines; setWarnings([{ message, from, to? }]) underlines problems; the readonly attribute stops edits.
