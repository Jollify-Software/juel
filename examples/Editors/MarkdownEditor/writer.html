Markdown Editor: the writer look

writer turns on a calmer look: headings bold and not underlined, syntax marks dimmed, and a leading --- front-matter block read as front matter (without it, its last line parses as a setext heading). prose sets the text in a proportional font (--juel-font-prose); code and front matter stay monospace. Both are off by default, and the editor then looks as it always has.

Default

writer prose

setDividers

setDividers([{ offset, label }]) draws a rule above the line at each offset, with its label in a gutter beside it (here, a slide number for each # heading).

front-matter-chip

front-matter-chip="Deck settings" folds the leading front matter into a chip with that name. Clicking the name fires front-matter-open; the chevron shows or hides the YAML.
