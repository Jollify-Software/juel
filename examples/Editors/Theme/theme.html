Theme Picker

window.juel.theme is the actual abstraction — it applies a theme name as data-theme on <html>, persists it, and fires a theme-changed event on document so any code (or any number of picker instances) can react. <juel-theme-toggle> and <juel-theme-select> are just two thin UIs built on top of it — what a theme actually changes visually is entirely up to your own CSS.

Toggle

<juel-theme-toggle> — a binary light/dark switch, built on juel-toggle.

Select

<juel-theme-select themes="..."> — an open-ended list of named themes, using the same key: value; ... syntax as juel-shape's args.

Both stay in sync

Both pickers above and this demo box all listen for theme-changed — change either picker and everything updates together.

This box's background/text/border are styled per [data-theme] via plain CSS in this page — nothing juel-specific.

Custom UI

Any UI can drive the same mechanism directly — no picker component required.
