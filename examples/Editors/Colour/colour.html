Colour

<juel-colour value="#ff0000"> is a click-to-open colour picker (native colour input, hex field, and preset swatches). It fires value-changed whenever the colour changes, and its context/property attributes optionally write the picked value straight onto another object.

Basic

Live preview

Palette and recent

.palette replaces the eight swatches (a name each, e.g. theme colours and an accent); .recent adds a "Recent" row.

Near a right edge

In a narrow scrolling panel, a swatch at the right edge opens its popup leftwards, so the panel doesn't clip it.
