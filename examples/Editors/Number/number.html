Number

<juel-number label="..." value="..."> is a labelled type="number" input. Fires value-changed with the parsed numeric value as you type.

Basic

With units

units="px,em,rem,%" makes it a quantity: type 48px or 3, ArrowUp/ArrowDown step it (Shift for ten), and the menu changes the unit. Empty is allowed. Events carry { value, unit, text }.
