juel-select: an option for no value

When one of the options has an empty value ('' or null), it stands for "no value": it shows when the value is empty, and there's no "Choose…" placeholder. Without one, "Choose…" is first while nothing is chosen.

With a value and no placeholder of its own, "Choose…" isn't offered beside the real choices.

A placeholder the page sets stays as a way back to no value, as a style panel's theme choice does.

With required there's no placeholder at all: one of the choices must be picked.
