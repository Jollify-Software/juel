Gradient Editor

<juel-gradient-editor for="#el" css-property="background-image"> visually edits a CSS gradient — a comma-separated stack of layers, each a linear / radial / conic gradient (incl. repeating-*) or a flat colour. Drag stops on the track, click the track to add one, and use the geometry controls for angle / to side, radial shape + size + centre, or conic from + centre. Every edit is one undo step (the ↶ ↷ buttons, or .undo() / .redo()). Changes are applied to the target's inline style live.
