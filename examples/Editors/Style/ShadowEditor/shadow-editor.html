Shadow Editor

<juel-shadow-editor for="#el"> visually edits a CSS box-shadow — a stack of shadows, each with inset, X / Y offset, blur, spread and a colour + opacity. Drag inside the preview to set the offset; sliders do the rest. Every edit is one undo step (↶ ↷ or .undo() / .redo()), applied to the target's inline style live.
