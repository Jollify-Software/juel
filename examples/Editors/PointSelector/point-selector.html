Point Selector

<juel-point-selector> puts the page into a crosshair "pick a point" mode. Click Select Point: a full-screen overlay dims the page and swallows all input, so the next click anywhere on screen fires point-selected with { x, y, pageX, pageY } (and doesn't also activate whatever was under the cursor). Right-click or Esc fires point-cancelled. Add the input attribute to also expose editable X / Y number fields.
