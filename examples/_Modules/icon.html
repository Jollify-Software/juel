Icon

window.juel.icon reads icons out of CSS custom properties named --icon-<name> (each one a data-URL SVG). Icons are usually just applied as a class — <span class="icon smile"></span> — but the module also exposes ways to pull an icon out as markup.

As a class

The normal way to show an icon — no JS needed, just .icon.<name> plus a size (sm/md/lg).

get() vs use()

juel.icon.get(name) returns a self-contained <svg> string — simple, but duplicates the full path data every time it's called. juel.icon.use(name) instead injects the icon once into a shared, hidden sprite and returns a small <svg><use> reference to it — cheaper when the same icon appears many times on a page.

exists()

Checks whether a --icon-<name> custom property is defined, without rendering anything.
