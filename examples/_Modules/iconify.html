Iconify

window.juel.icon.iconify(element?) scans <li> elements (every <ul> on the page, or just the one passed in) for a short text code at the start — e:, t:, yt:, fb:, and so on — and replaces it with the matching brand/contact icon. It's meant for turning a plain contact list into an iconified one without hand-writing markup for each row. It doesn't run automatically; call it once after your content is in the DOM.

Before

The source list, before iconify() runs:

<li>e: hello@jollify.app</li>
<li>t: 01234 567890</li>
<li>w: jollify.app</li>
<li>x: @jollify</li>
<li>fb: jollify</li>
<li>yt: (https://youtube.com/@jollify)</li>
<li>bs: @jollify</li>
<li>wa: @jollify</li>
<li>tt: @jollify</li>

After

The same list, once iconify() has run against it. A (url) right after the colon becomes a link around the icon.

  • e: hello@jollify.app
  • t: 01234 567890
  • w: jollify.app
  • x: @jollify
  • fb: jollify
  • yt: (https://youtube.com/@jollify)
  • bs: @jollify
