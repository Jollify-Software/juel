Message Box

window.juel.messageBox shows a modal dialog. error(), success(), warning() and question() are shorthands around the general-purpose show(args), which also supports prompts (a single text field, several named fields, or a markdown-rendered value) and returns a promise that resolves with whatever the user entered. Only one message box shows at a time — calling show() again while one is already open is a no-op.
