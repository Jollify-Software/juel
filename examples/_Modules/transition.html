Transition

On page load, initTransitions() runs automatically (wired up in JuelGlobal.ts) over every element whose class name contains transition. Each one — except the first — briefly takes on the *previous* such element's computed size/color/position, then animates from there to its own actual styling. It's a FLIP-style effect for making a freshly-rendered element look like it grew out of an earlier one, without actually moving any DOM nodes.
