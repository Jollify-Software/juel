Audio

window.juel.audio tracks in-flight sounds by src. play(src) starts a new sound, or resumes it if paused — returns false only if that src is already actively playing. pause(src) pauses in place (still tracked, so play() resumes it); stop(src) pauses, rewinds, and forgets it entirely. list() returns the currently-tracked src keys.
