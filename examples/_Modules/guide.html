Guide

window.juel.guide walks visitors through a page with a dimmed spotlight overlay (inspired by Driver.js), a highlight box around each step's target element, and a tooltip. start(steps, options) takes an array of { selector, title, description } steps; arrow keys move between steps and Escape ends the tour early. The highlight box smoothly animates its position, size, and corner radius between steps.
