Toast

window.juel.toast shows a stack of dismissing-after-a-delay notifications in the bottom-right corner. success(), error(), warning() and into() are shorthands for show({ message, type, duration }). Every call shares one stack, so multiple toasts queue underneath each other instead of overlapping.

Types

Each type gets its own color and, for success, a longer default duration (5s vs 3s).

Stacking

Firing several at once queues them in a single stack rather than overlapping.
