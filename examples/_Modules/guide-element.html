Guide element

<juel-guide> holds a tour as markup: each <juel-guide-step> has a target (a selector; >>> crosses into a shadow root), a title, optional placement and wait, and its content is the step's HTML body. A step whose target isn't on the page is skipped. Arrow keys move, Escape skips the tour, and storage-key remembers that it was seen. Open with ?look&theme=dark for the dark look.
