Data Grid

<juel-data-grid> fetches and paginates a data set, rendering each record through a Lit template string set on .template (with this bound to the record — e.g. ${this.text}). Point it at a REST-style endpoint with url/list (GET, appending currentPage/pageSize query params), or set .retrieve to a (pagination) => Promise<{ data, count }> function for any other data source — this page uses an in-memory data set via .retrieve so it needs no backend. Set input to show a built-in search box that filters by text-field.
