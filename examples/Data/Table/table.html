Table

<juel-table> renders data (an array of objects), with columns from <juel-column slot="columns"> children or, without any, from the first row's keys. A column can hold a <template> with {{field}} placeholders.

Columns and templates

Sorting

sortable on the table makes every bound column sortable (or set it per <juel-column sortable>). Click a header to cycle ascending, descending and unsorted. Numbers sort by value and text in natural order; empty values go last. sort-field/sort-direction hold the sort, sort-changed fires on each change, and external-sort leaves ordering to the page.

Sorted by spend, descending.

Empty state

With no rows the table shows empty-text (default "No rows"), or whatever is in its empty slot.
